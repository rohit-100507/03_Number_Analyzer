# Number Analyzer - Python

This is one of my beginner Python projects.

I created this program while learning **while loops, if-else statements, variables, and basic calculations** in Python.
I wanted to practice handling multiple numbers and performing different calculations on them,
so I created a Number Analyzer.

## What This Program Does

* Takes the total number of values from the user.
* Uses a `while` loop to take numbers one by one.
* Checks whether each number is even or odd.
* Counts the total number of even and odd numbers.
* Finds the largest and smallest number.
* Calculates the total sum of all numbers.
* Calculates the average of the entered numbers.
* Displays all the results at the end.

## Python Concepts I Practiced

* `input()`
* `int()`
* `while` loop
* `if-else` statements
* `%` modulus operator

* `+=` operator
* Basic arithmetic
* `print()`

## Example

If the user enters:

```text
Enter Total Number To Check: 5

Enter Number : 10
Enter Number : 7
Enter Number : 25
Enter Number : 4
Enter Number : 12
```

The program prints:

```text
==================================================
              RESULT
==================================================
Even Count     :  3
Odd Count      :  2
Largest Number :  25
Lowest Number  :  4
Total Sum      :  58
Average        :  11.6
```
